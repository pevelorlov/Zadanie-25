# День 23. Query rewrite, фильтрация и reranking

## Пять режимов

Один и тот же вопрос можно выполнить пятью независимыми способами:

1. `baseline` — исходный вопрос и обычная сортировка по cosine similarity;
2. `rewrite` — DeepSeek формирует самостоятельную поисковую фразу;
3. `filter` — исходный вопрос, затем отсечение кандидатов ниже similarity;
4. `rerank` — исходный вопрос, затем локальный multilingual CrossEncoder меняет порядок кандидатов;
5. `combined` — rewrite → similarity-фильтр → reranker.

`candidate top-K` задаёт число чанков после векторного поиска, а `final top-K` —
максимум чанков, передаваемых основной модели. Оба значения настраиваются
независимо, но финальное не может превышать число кандидатов.
Стартовый порог `0.83` подобран по текущему индексу; он является настройкой
конкретной embedding-модели и корпуса, а не универсальным стандартом.

## Модели и вызовы

Эмбеддинги по-прежнему создаёт локальная `intfloat/multilingual-e5-small`.
Реранжирование выполняет локальная CPU-модель
`cross-encoder/mmarco-mMiniLMv2-L12-H384-v1`, которая загружается лениво только
для режимов `rerank` и `combined`. Query rewrite является коротким отдельным
вызовом выбранной модели DeepSeek.
Оценка CrossEncoder используется только для сортировки: это сырой model score,
а не вероятность релевантности. Порог применяется к cosine similarity исходной
embedding-модели.

## Интерфейс

В обычном чате доступны режим, стратегия chunking, top-K до/после и порог.
Лаборатория Дня 23 выполняет для одного вопроса один rewrite и пять ответов,
показывает similarity, оценки reranker, число кандидатов до и после фильтра и
реально переданные чанки. Результат сохраняется в `data/rag_evaluations.json`.

# День 24. Цитаты, источники и анти-галлюцинации

## Режим в обычном чате

Сначала включается **RAG**, затем становится доступен переключатель
**«Проверяемый»**. В этом режиме ответ содержит ссылки `[1]`, отдельный список
источников и отдельный список дословных цитат.

Порядок обработки:

1. локальный векторный поиск по исходному вопросу;
2. отсечение чанков ниже настраиваемого similarity-порога;
3. при пустой выдаче — локальный ответ «не знаю» без DeepSeek;
4. при достаточной релевантности — выбранный конвейер Дня 23;
5. структурированный ответ модели;
6. проверка `chunk_id`, ссылок и точного вхождения цитат;
7. одна исправляющая попытка; затем безопасный отказ, если проверка снова не прошла.

Метаданные `source` и `section` всегда берутся из сохранённого чанка, а не из
текста модели.

## Лаборатория Дня 24

Раздел **«Управление RAG»** выполняет один проверяемый ответ и отдельный
LLM-вызов, который оценивает, подтверждается ли смысл ответа его цитатами.
Программная и смысловая проверки сохраняются раздельно в
`data/rag_evaluations.json`.

Контрольный набор состоит из 10 прежних вопросов с ответами в базе и 5
дополнительных вопросов, для которых ожидается «не знаю». Дополнительный набор
находится в `docs/day24_control_questions.json`.
